# 3-isogeny Selmer group experiments

SageMath code and matrix-frequency data accompanying **Experiments on 3-isogeny
Selmer groups of elliptic curves with a 3-torsion point**, by Ariel Weiss and
Dongchen Zou.

The experiments test the conjectural equidistribution of the reduced
cubic-residue matrices $M'_{A,B}$ defined in Section 3 of the paper. They use
two sampling procedures: exhaustive enumeration in a sifted height interval,
and random sampling with a prescribed number of prime factors of $B$.

## Mathematical setting

We consider elliptic curves over $\mathbb Q$ in the normalised form

$$
E_{A,B}: y^2+Axy+By=x^3,
\qquad A,B\in\mathbb Z,\quad B>0,
$$

where $p\mid A$ implies $p^3\nmid B$. The discriminant is
$\Delta_{A,B}=B^3(A^3-27B)$. Both experiments restrict to good reduction at $3$
($3\nmid AB$) and exclude the exceptional subfamilies in which $B$ or
$A^3-27B$ is a cube.

Let $\phi:E_{A,B}\to E_{A,B}'$ be the $3$-isogeny with kernel generated by
$(0,0)$, and let $\widehat\phi$ be its dual. The matrix $M_{A,B}$ describes
$\mathrm{Sel}_{\hat\phi}(E_{A,B}')$ as a subspace of
$\mathbb Q^\times/(\mathbb Q^\times)^3$. The class $[B]$ gives a nonzero
torsion contribution; removing it gives

$$
\ker M'_{A,B}\simeq
\mathrm{Sel}_{\widehat\phi}(E'_{A,B})/\langle[B]\rangle.
$$

If $M'_{A,B}$ has dimensions $a\times b$ and rank $r$ over $\mathbb F_3$, then

$$
\dim_{\mathbb F_3}\mathrm{Sel}_{\phi}(E_{A,B})=a-r,
\qquad
\dim_{\mathbb F_3}\mathrm{Sel}_{\widehat\phi}(E'_{A,B})=b-r+1.
$$

Here $b=\omega(B)-1$ and $a=\omega_1(A^3-27B)$, where $\omega$ counts distinct
prime factors and $\omega_1$ counts those congruent to $1\pmod 3$. In the
paper's notation, $b=m$, $a=m+t$, and the global Selmer ratio is

$$
c(\phi,E_{A,B})=3^{t-2}=3^{a-b-2}.
$$

The experiments group matrices by their dimensions and compare their
frequencies with the uniform distribution on
$\mathrm{Mat}_{a\times b}(\mathbb F_3)$.

## Running the code

The scripts require [SageMath](https://doc.sagemath.org/html/en/installation/),
with `numpy` and `psutil` available in its Python environment.

Run all commands below from the `Code` directory, so that the scripts can load
`selmer_shared.sage`:

```sh
cd Code
```

For a small example, generate 10,000 accepted samples with two prime factors:

```sh
sage 3-selmer-factor.sage \
  --primes 1000 --factors 2 --trials 10000 --method box \
  --nprocesses 1 --output ../runs/example.jsonl
```

Both drivers accept the following options:

| Option | Meaning |
| --- | --- |
| `--nprocesses k` | Number of worker processes; `1` runs serially; the default is the CPU count |
| `--output path` | Output file, relative to the current working directory |
| `--log-every k` | Print progress every $k$ completed batches or serial blocks |
| `--overwrite` | Replace an existing output file; otherwise the script refuses to overwrite it |

Output directories are created automatically. Use distinct output paths for
independent runs; interrupted runs are not resumed automatically. The examples
write to `runs/` at the repository root.

## Sifted height experiment

The paper uses the height

$$
H(E_{A,B})=\max(|A|^3,B).
$$

The command-line arguments are **cube-root height bounds**:
`--min_height h0 --max_height h1` enumerates the admissible normalised pairs with

$$
h_0^3\le H(E_{A,B})\le h_1^3.
$$

Both bounds are inclusive. The option `--min_prime K` excludes pairs for which
some prime $p<K$ divides $B(A^3-27B)$. The prime $3$ is always excluded,
irrespective of the cutoff. Both signs of $A$ are included.

For example, the parameters for H-1000-100 are:

```sh
sage 3-selmer-height.sage \
  --min_height 1000 --max_height 1010 --min_prime 100 \
  --nprocesses 4 --output ../runs/H-1000-100.jsonl
```

The seven height experiments in Table 1 use:

| --- | ---: | ---: | ---: | ---: |

| H-1000-300 | 1000 | 1010 | 300 | 816,536,769 |

These are substantial computations: even a narrow height interval requires
scanning values of $B$ up to the cube of `--max_height`.

## Prime factor experiment

The parameter `--primes N` specifies a pool consisting of the **first $N$ primes
greater than $3$**. For each sample, the code chooses $n$ distinct primes
uniformly from this pool, where $n$ is specified by `--factors n`, and sets

$$
B=\prod_{i=1}^n p_i^{e_i},
\qquad
\Pr(e_i=k)=p_i^{-(k-1)}-p_i^{-k}\quad(k\ge1).
$$

The exponents are sampled independently. Cubes $B$ are discarded. The code
then samples $A$, resampling it until $3\nmid A$ and the pair is normalised.
Pairs for which $A^3-27B$ is a cube are discarded, as are reduced matrices with
more than $12$ entries. Every retained matrix has $n-1$ columns.

The two sampling methods used in the paper are:

| Option | Sampling of $A$ | Experiments |
| --- | --- | --- |
| `--method box` | Uniform in an interval about $0$ on the scale $B^{1/3}$, subject to the conditions above | $n=2$, marked with an asterisk in the paper |
| `--method height` | Uniform magnitude near $B^{1/3}$, with a random sign, subject to the conditions above | $n\ge3$ |

For the precise integer bounds, put $h=\lfloor B^{1/3}\rfloor$,
$L=\lfloor9h/10\rfloor$, and $U=\lfloor11h/10\rfloor$.
The `height` method samples $L\le |A|<U$; the `box` method samples
$-U\le A<U$. The default is `height`, so **specify `--method box` for the
two-prime experiments**.

The argument `--trials T` specifies the number of **accepted samples**, after
all exclusions. Repeated occurrences of a curve are counted with multiplicity.
For example, the parameters for F10k-7 are:

```sh
sage 3-selmer-factor.sage \
  --primes 10000 --factors 7 --trials 124800000 --method height \
  --nprocesses 4 --output ../runs/F10k-7.jsonl
```

The experiments in Table 5 use:

## Data format and matrix conventions

Each line of a JSONL file records a reduced matrix and its multiplicity:

```json
{"pair": [2, 3], "matrix": "012120", "count": 57}
```

Here `pair` gives the numbers of rows and columns, and `matrix` lists the
entries row by row, using `0`, `1`, and `2` for elements of $\mathbb F_3$.
Thus the example records 57 occurrences of

$$
\begin{pmatrix}
0&1&2\\
1&2&0
\end{pmatrix}.
$$

An empty string represents a matrix with no rows or no columns; its dimensions
are still recorded in `pair`. These are the *trivial matrices* in the paper.
An all-zero matrix with both dimensions positive is nontrivial in this
terminology.

The code uses the conventions of Section 3:

- In the full matrix, columns first list the primes $p\mid\gcd(A,B)$ with
  $p\equiv1\pmod3$, then the remaining prime divisors of $B$, with increasing
  order within each group. Rows list the same first group, followed by the
  primes $q\mid A^3-27B$ with $q\equiv1\pmod3$ and $q\nmid B$, again in
  increasing order.
- At each row prime $q$, choose the smaller of the two nontrivial cube roots
  of unity in $\{1,\ldots,q-1\}$ as $\zeta_q$. The values
  $1,\zeta_q,\zeta_q^2$ of the cubic residue symbol are encoded by $0,1,2$.
- To obtain $M'_{A,B}$, delete the last column, in the ordering above, for which
  $v_p(B)\not\equiv0\pmod3$.

For example, read one record and reconstruct its matrix in Sage:

```sage
import json

with open("../runs/example.jsonl") as f:
    record = json.loads(next(f))

a, b = record["pair"]
M = matrix(GF(3), a, b, [int(x) for x in record["matrix"]])
r = M.rank()
phi_dimension, dual_phi_dimension = a - r, b - r + 1
```

## Recovering the paper's tables

Before computing statistics, combine any separate batches of the same
experiment by adding counts for identical `(pair, matrix)` keys. In particular,
the following experiments combine an initial 100,000,000 samples with an
additional batch:

| Experiment | Additional samples | Combined total |
| --- | ---: | ---: |
| F10k-4 | 10,000,000 | 110,000,000 |
| F10k-5 | 780,000 | 100,780,000 |
| F10k-7 | 24,800,000 | 124,800,000 |

For F10k-7, the two files are `factor_N10000_n7.jsonl` and
`factor_N10000_n7-2.jsonl`. Tables 5 and 8 also use the five datasets F1k-8
through F1k-12, each containing 100,000,000 accepted samples.

| Paper table | Data and calculation |
| --- | --- |
| 1 | Total, trivial, and nontrivial counts for the height experiments |
| 2 | Nontrivial matrix blocks from H-3250 |
| 3 | Nontrivial matrix blocks from the combined F10k-7 data |
| 4 | H-1000 data stratified by the smallest prime divisor of $B(A^3-27B)$ |
| 5 | Total, trivial, and nontrivial counts for the prime factor experiments |
| 6 | Selected prime factor blocks, comparing $N=1000,10000,100000$ for fixed $n$ |
| 7 | All height block statistics |
| 8 | All prime factor block statistics |

For Table 4, the four H-1000 datasets are nested. Subtract counts for matching
matrices: cutoff 100 minus 300, 300 minus 500, and 500 minus 800 give the strata
$[100,300)$, $[300,500)$, and $[500,800)$ for the smallest prime divisor. The
cutoff-800 dataset gives the final stratum. Compute statistics only after
taking these differences.

## Individual Selmer groups

To compute an individual example, start Sage in the `Code` directory and run:

```sage
load("selmer_shared.sage")
selmer_ranks(1, 14)
selmer_sizes(1, 14)
```

For an admissible pair $(A,B)$, `selmer_ranks(A, B)` returns

```text
(phi_dimension, dual_phi_dimension)
```

and `selmer_sizes(A, B)` returns the corresponding powers of $3$, in the same
order. These functions use the full matrix $M_{A,B}$ and require good reduction
at $3$ after normalisation. They do not impose the experiment drivers' cube
exclusions.
